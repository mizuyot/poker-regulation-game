# ポーカー店経営 5年 — 設計メモ v0.1

既存の「大会設計ゲーム」（`docs/index.html`）の姉妹作。大会という一回の催しではなく、**店を5年間回す**とき、同じ法的論点（賭博・風営法の賞品提供・許可）がどう効いてくるかを、経営の手触りで体験させる。

> 法的助言ではない。摘発確率・処分の段階・金額はすべてゲーム用の架空の値。条文の逐語は `docs/questions.json` の `provisions`（正本）からだけ引く。

## 1. コアループ

```
開店前の設定（立地・卓数・ルール・許可）
        ↓
  1か月 = 6秒（×1/×2/×4）で時間が流れる
        ↓
  客が来る → 売上（＋◯円）→ 家賃・ディーラー代・広告費が引かれる
        ↓
  違反があれば毎月「立入り」の抽選 → 処分 or 逮捕
        ↓
  卓の増減・広告・ルール変更で手を入れる
        ↓
  60か月後の累計利益がスコア
```

**勝ち筋の緊張**：換金・景品は客を増やす（需要 ×2.6 / ×1.5）。でも、目立つほど（立地・広告・卓数）監視が強まる。**稼ぐための手がそのまま、捕まりやすさを上げる**。

## 2. 設定項目

| 項目 | 選択肢 | 効き方 |
|---|---|---|
| 立地 | 繁華街 / 駅前 / 雑居ビル上階 / 郊外ロードサイド | 家賃・人通り（需要）・目立ちやすさ（摘発率） |
| 卓数 | 1〜12 | 月の受け入れ上限（1卓110人）とディーラー代。卓数が多いほど摘発率も上がる |
| ルール | 換金なし・景品なし / 景品あり / 換金あり | 需要と客単価。違反の種類（なし / 行政 / 刑事） |
| 許可 | 許可を取って開く（申請費40・3か月待ち） / 無許可ですぐ開く | 開店時期。無許可は行政処分の対象 |
| 広告（開店後） | Lv0〜3 | 需要↑・届く範囲（画面の円）↑・摘発率↑ |

## 3. 違反と処分（ゲーム上の扱い）

| 状態 | 処理 | 参照する条文（provisions のID） |
|---|---|---|
| 換金なし・景品なし＋許可あり | 摘発の対象外 | keiho185（参考） |
| 景品あり | 行政処分ラダー：**指示 → 営業停止3か月 → 廃業（罰金100）** | fueiho23-2, fueiho2-1 |
| 無許可 | 行政処分ラダー（同上） | fueiho2-1 ※罰則条文は未収録 |
| 換金あり | **摘発＝逮捕。スコア0（利益没収扱い）** | keiho185, keiho186 |
| 換金をやめたあと12か月 | 刑事リスクが半分の重みで残る（過去は遡る） | 同上 |

- 「指示」の場面では **是正する／このまま続ける** を選ばせる。是正すると換金なし・許可申請（3か月休業）に切り替わる。
- 摘発率（月）＝ 違反ごとの基礎率の和 × 立地の目立ちやすさ × (1 + 0.25×広告Lv) × (1 + 卓数/8) × (1 + 監視熱)
- 監視熱：換金営業中は毎月 +0.03、指示・停止で +0.5、平常時は −0.02/月。

## 4. バランス確認（`scripts/sim_shop.py`、固定戦略×300回の期待値）

固定戦略で各組み合わせの最善の卓数・広告を探した結果（万円、架空値）：

| 立地 | 合法（換金なし＋許可） | 景品あり＋許可 | 換金あり＋許可 |
|---|---|---|---|
| 繁華街 | **9,239**（完走100%） | 5,876（完走22%） | 974（逮捕97%） |
| 駅前 | 6,878 | 7,360（完走31%） | 2,466（逮捕92%） |
| 雑居ビル上階 | 3,666 | 7,237（完走70%） | **8,637（逮捕71%）** |
| 郊外 | 1,902 | 4,237 | 3,529（逮捕83%） |

読み取り：
- **期待値の最大は合法×繁華街×12卓×広告全開**。合法でも大きく張れる店がいちばん稼ぐ。
- 誘惑は「目立たない場所で小さく換金」。期待値は合法の最大に近いが、7割で0になる。これが「賭けとしての違法営業」の体験。
- 景品は「立入りで是正」まで含めれば中庸。ラダーがあるので一発退場ではない。

数値は `docs/shop/shop.json` を変えて `python3 scripts/sim_shop.py docs/shop/shop.json` で再確認する。

## 5. UI（添付参照の白黒アイソメ）

- 中央：円形の店（立ち上がった壁、黒い楕円卓）。入口は手前の切れ目。
- 店の上の黒ピル：`5卓 : 100%`（稼働率）。許可待ち・営業停止のときは状態を表示。
- 店を囲む点線の弧：**監視ゲージ**（摘発率に比例して伸びる）。
- 大きな細線の円：**広告の届く範囲**。円周上の小さな丸が5年の進み（時計）。
- 斜めの道：立地（人通りに比例して太くなる）。
- 人：黒いシルエット＋影。来店客は卓へ、通行人は通り過ぎる。警察は白抜き＋帽子で入ってくる。
- 右上：所持金（チップアイコン）、来客/月（需要）、経過、5年累計利益、監視バー。
- 下のドック：`1 広告` `2 卓＋` `3 卓−` `4 ルール`。上のタグに **集客不足／満卓／監視強め／許可待ち／営業停止**。
- 左上：一時停止（Space）と速度切替。

## 6. 正本とデータの流れ（RAG資産化）

```
docs/questions.json (provisions: 条文の正本)
docs/shop/shop.json  (ゲームパラメータの正本)
        │  python3 scripts/build_shop.py
        ├─→ docs/shop/index.html に両方を埋め込み（使う条文だけ抜き出す）
        └─→ data/shop_rag.jsonl（立地・ルール・許可・リスク定義＋条文ID・出典URL）
プレイ終了画面 →「プレイログを保存（JSONL）」→ 端末に保存（送信しない）
```

- 条文はコピーしない。参照IDで引き、`verified: false` のものは逐語を出さず「未確認」と表示する。
- 正本に無い論点（無許可営業の罰則など）は `missingSource` に**欠測として明記**し、画面にも出す。
- プレイログ（設定・ルール変更・処分・選択・月次収支）は、ローカルのRAGに入れて「どの設計で、どこで捕まったか」を後で検索・集計できる形にしてある。

## 7. 次の拡張候補

1. **イベントカード**：既存ゲームの `events` / `designerNotes` を店舗版に流用（例：常連から「景品出してよ」、同業の摘発ニュース、深夜営業の誘惑）。
2. **大会開催**：店から大会を打つと、大会設計ゲームの論点（原資の分離・継続性）がつながる。
3. **深夜営業・年齢確認・広告表現**：違反の種類を増やす（条文を正本に追加してから）。
4. **ランキング**：完走かつ合法の最高利益と、全体最高を別枠で出す。
5. **リーガルレビュー**：処分ラダー・「没収扱い」の表現・条文の対応付けを、既存TODOと同じく弁護士レビューに回す。
