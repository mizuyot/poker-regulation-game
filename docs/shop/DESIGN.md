# ポーカー店経営 5年 — 設計メモ v0.1

既存の「大会設計ゲーム」（`docs/index.html`）の姉妹作。大会という一回の催しではなく、**店を5年間回す**とき、同じ法的論点（賭博・風営法の賞品提供・許可）がどう効いてくるかを、経営の手触りで体験させる。

> 法的助言ではない。摘発確率・処分の段階・金額はすべてゲーム用の架空の値。条文の逐語は `docs/questions.json` の `provisions`（正本）からだけ引く。

## 1. コアループ

```
開店前の設定（立地・卓数・ルール・許可）
        ↓
  1か月 = 6秒（×1/×2/×4）で時間が流れる
        ↓
  客が来る → 売上（＋◯円）→ 家賃・ディーラー代・広告費が引かれる
        ↓
  違反があれば毎月「立入り」の抽選 → 処分 or 逮捕
        ↓
  卓の増減・広告・ルール変更で手を入れる
        ↓
  60か月後の累計利益がスコア
```

**勝ち筋の緊張**：換金・景品は客を増やす（需要 ×2.6 / ×1.5）。でも、目立つほど（立地・広告・卓数）監視が強まる。**稼ぐための手がそのまま、捕まりやすさを上げる**。

## 2. 設定項目

| 項目 | 選択肢 | 効き方 |
|---|---|---|
| 立地 | 繁華街 / 駅前 / 雑居ビル上階 / 郊外ロードサイド | 家賃・人通り（需要）・目立ちやすさ（摘発率） |
| 卓数 | 1〜12 | 月の受け入れ上限（1卓110人）とディーラー代。卓数が多いほど摘発率も上がる |
| ルール | 換金なし・景品なし / 景品あり / 換金あり | 需要と客単価。違反の種類（なし / 行政 / 刑事） |
| 許可 | 許可を取って開く（申請費40・3か月待ち） / 無許可ですぐ開く | 開店時期。無許可は行政処分の対象 |
| 広告（開店後） | Lv0〜3 | 需要↑・届く範囲（画面の円）↑・摘発率↑ |

## 3. 違反と処分（ゲーム上の扱い）

| 状態 | 処理 | 参照する条文（provisions のID） |
|---|---|---|
| 換金なし・景品なし＋許可あり | 摘発の対象外 | keiho185（参考） |
| 景品あり | 行政処分ラダー：**指示 → 営業停止3か月 → 廃業（罰金100）** | fueiho23-2, fueiho2-1 |
| 無許可 | 行政処分ラダー（同上） | fueiho2-1 ※罰則条文は未収録 |
| 換金あり | **摘発＝逮捕。スコア0（利益没収扱い）** | keiho185, keiho186 |
| 換金をやめたあと12か月 | 刑事リスクが半分の重みで残る（過去は遡る） | 同上 |

- 「指示」の場面では **是正する／このまま続ける** を選ばせる。是正すると換金なし・許可申請（3か月休業）に切り替わる。
- 摘発率（月）＝ 違反ごとの基礎率の和 × 立地の目立ちやすさ × (1 + 0.25×広告Lv) × (1 + 卓数/8) × (1 + 監視熱)
- 監視熱：換金営業中は毎月 +0.03、指示・停止で +0.5、平常時は −0.02/月。

## 4. バランス確認（`scripts/sim_shop.py`、固定戦略×300回の期待値）

固定戦略で各組み合わせの最善の卓数・広告を探した結果（万円、架空値）：

| 立地 | 合法（換金なし＋許可） | 景品あり＋許可 | 換金あり＋許可 |
|---|---|---|---|
| 繁華街 | **9,239**（完走100%） | 5,876（完走22%） | 974（逮捕97%） |
| 駅前 | 6,878 | 7,360（完走31%） | 2,466（逮捕92%） |
| 雑居ビル上階 | 3,666 | 7,237（完走70%） | **8,637（逮捕71%）** |
| 郊外 | 1,902 | 4,237 | 3,529（逮捕83%） |

読み取り：
- **期待値の最大は合法×繁華街×12卓×広告全開**。合法でも大きく張れる店がいちばん稼ぐ。
- 誘惑は「目立たない場所で小さく換金」。期待値は合法の最大に近いが、7割で0になる。これが「賭けとしての違法営業」の体験。
- 景品は「立入りで是正」まで含めれば中庸。ラダーがあるので一発退場ではない。

数値は `docs/shop/shop.json` を変えて `python3 scripts/sim_shop.py docs/shop/shop.json` で再確認する。

## 5. UI（添付参照の白黒アイソメ）

- 中央：円形の店（立ち上がった壁、黒い楕円卓）。入口は手前の切れ目。
- 店の上の黒ピル：`5卓 : 100%`（稼働率）。許可待ち・営業停止のときは状態を表示。
- 店を囲む点線の弧：**監視ゲージ**（摘発率に比例して伸びる）。
- 大きな細線の円：**広告の届く範囲**。円周上の小さな丸が5年の進み（時計）。
- 斜めの道：立地（人通りに比例して太くなる）。
- 人：黒いシルエット＋影。来店客は卓へ、通行人は通り過ぎる。警察は白抜き＋帽子で入ってくる。
- 右上：所持金（チップアイコン）、来客/月（需要）、経過、5年累計利益、監視バー。
- 下のドック：`1 広告` `2 卓＋` `3 卓−` `4 ルール`。上のタグに **集客不足／満卓／監視強め／許可待ち／営業停止**。
- 左上：一時停止（Space）と速度切替。

## 6. 正本とデータの流れ（RAG資産化）

```
docs/questions.json (provisions: 条文の正本)
docs/shop/shop.json  (ゲームパラメータの正本)
        │  python3 scripts/build_shop.py
        ├─→ docs/shop/index.html に両方を埋め込み（使う条文だけ抜き出す）
        └─→ data/shop_rag.jsonl（立地・ルール・許可・リスク定義＋条文ID・出典URL）
プレイ終了画面 →「プレイログを保存（JSONL）」→ 端末に保存（送信しない）
```

- 条文はコピーしない。参照IDで引き、`verified: false` のものは逐語を出さず「未確認」と表示する。
- 正本に無い論点（無許可営業の罰則など）は `missingSource` に**欠測として明記**し、画面にも出す。
- プレイログ（設定・ルール変更・処分・選択・月次収支）は、ローカルのRAGに入れて「どの設計で、どこで捕まったか」を後で検索・集計できる形にしてある。

# v0.2 方針（未実装）

## A. 違法アクションの原則

1. **違法は正解にしない。** どの違法戦略も、期待値は合法を下回る（目標は合法の0.95倍以下）。ただし運が良ければ大きく勝てる（上位10%で合法の2倍以上）。「分かっていて賭ける」ゲームにする。
2. **どのアクションにも「改善命令」と「逮捕」の両方の確率を持たせる。** 毎月、アクションごとに別々に判定する。
3. **確率は数字で画面に出す。** 補正後の最終値を「今月 逮捕2.4% / 改善命令15%」のように表示する。監視熱は廃止する。

## B. 改善命令の流れ

```
違法アクション中 ─(月 p命令)→ 改善命令
   ├ 罰金（合法月利の6か月分）
   ├ 2か月間、そのアクションは強制停止
   └ 明け直後から6か月、売上50%減（風評。合法営業でも減る）
        └ 以降、店全体の逮捕率 ×4（2回目の命令で ×16）＝「要注意店」
```

## C. 逮捕確率の設計

- 基本は **2%/月**（換金）。
- 違法を続けた月数ぶん、**+0.2%/月**ずつ上がる（噂が広がる）。
- 改善命令を受けるたびに **×4**。
- やめた後も **12か月は半分の確率が残る**（遡及）。
- 逮捕すると、その場でゲーム終了。換金での逮捕はスコア0（没収扱い）。それ以外の逮捕は罰金を引いた残りがスコアになる。

### 検証（`scripts/sim_orders.py`。単価5倍、合法の売上:費用 = 2:1）

| 推奨値 | 期待値（合法比） | 逮捕率 | 上位10% |
|---|---|---|---|
| ずっと違法 | 0.00 | 100% | — |
| 最善の違法戦略（3か月だけ） | 0.96 | 26% | 1.4倍 |
| 12か月だけ違法して撤退 | 0.85 | 46% | **2.3倍** |

推奨値：逮捕2%＋0.2%/月、命令15%/月、命令罰金は合法月利の6か月分、明け後6か月は売上−50%、命令ごとに逮捕率×4、遡及12か月（半分の確率）。

## D. 違法アクション一覧（確率は仮。立地の補正前）

| アクション | 効果 | 逮捕/月 | 命令/月 | 条文（正本） |
|---|---|---|---|---|
| 換金 | 単価×5 | 2% | 15% | keiho185・186 |
| 景品 | 来客×1.5 | 0.3% | 8% | fueiho23-2 |
| 無許可営業 | 3か月待ちなしで開店 | 0.5% | 6% | 罰則条文は未収録 |
| 深夜営業 | 営業時間×1.3 | 0.3% | 6% | 未収録 |
| 年齢確認を省く | 来客×1.1 | 0.5% | 4% | 未収録 |
| 誇大な広告 | 来客×1.3 | 0.1% | 6% | 未収録 |

- 「要注意店」の倍率（×4）は店単位で、全アクションにかかる。
- 未収録の条文は、正本（questions.json）に一次ソースから入れるまで、画面に「条文未収録」と出す。

## E. シムシティ的な楽しみ（候補）

1. **街が育つ**：毎年、周辺に駅・再開発・競合店・住宅が生える。立地の値は固定ではなく変わっていく。2号店も出せる。
2. **オーバーレイ表示**：需要・監視・苦情を、地図上のヒートマップで切り替えて見る。
3. **客の流れと種類**：初心者・常連・プロ・観光客。種類ごとに単価と来る時間帯が違い、流れが見える。
4. **近隣の満足度**：騒音・深夜営業・客引きで苦情が増え、苦情が改善命令の確率を上げる。防音などの設備投資で下げられる。
5. **スタッフ**：ディーラーを育てる・引き抜かれる。腕前で回転数と評判が変わる。
6. **内装・設備**：ドリンク、トーナメント設備、VIP席。店の作り込みの楽しみ。
7. **年次イベント**：取締り強化月間（確率↑）、ポーカーブーム（需要↑）、景気の波。
8. **アドバイザー**：会計士（月次損益グラフ）・弁護士（条文と一次ソース付きの助言カード）・常連（需要の噂）。
9. **大会開催**：店から大会を打つと、大会設計ゲームの論点（原資の分離・継続性）につながる。

## F. 実装の順番（案）

1. A〜Dの確率モデル（shop.json の `actions` 配列と、確率表示のUI）
2. 改善命令の演出（警察の来店 → 命令カード → 風評で売上が減る表示）
3. E-2 オーバーレイ、E-4 近隣の満足度（地図とリスクがつながる）
4. E-1 街の成長と2号店

# v0.3 改訂方針（未実装。v0.2のうち、ここと食い違う部分はv0.3を優先する）

## 0. 中心に置くもの

**「売上を作る客と、店を壊す客が同じ」という経営の難しさ**を中心に置く。警察に捕まるかどうかは中心にしない。

v0.2までは、合法営業の最適な設定が見つかると、その後は操作する理由が薄かった。違法には誘惑と事件があるのに、合法営業の面白さが足りなかった。v0.3では、合法営業の中で判断が続くようにする。

目指すプレイ後の感想：「あの常連を切って一度は赤字になったけど、初心者が戻ってきて店が復活した」と話したくなること。

## 1. 事件は「自分の経営判断から育つ」

事件は、くじで引くものにしない。**予兆 → 判断 → 結果 → 後日談** の4段で作る。

- 例：有名プレイヤーが常連になり、取り巻きも来て店は繁盛する。ところが初心者への態度が悪く、新規客が定着しない。スタッフからは注意してほしいと言われるが、彼は売上を支えている。注意を先延ばしにしていると、接客動画がSNSで拡散する。
- 早く対応すれば小さく収まる展開も用意する。毎回大炎上にはしない。
- 事件カードが出たら時間を止め、判断したら再開する。今のテンポは保つ。

## 2. 事件カード案（実在の事件の構造だけを取り出した架空の話）

| 事件 | 店長が悩む選択 | ゲームとして面白い部分 |
|---|---|---|
| 「あのコール、おかしくない？」配信卓で不正疑惑 | 配信を続ける／一時止めて調べる／当事者を一時的に卓から外す | 不正が確定する前に、売上と公平な対応を両立する |
| 一番お金を使う常連が、一番嫌われている | 個別に注意／全員に同じルールを当てる／出禁 | 目先の売上と初心者の定着がぶつかる |
| 契約したプロに過去の不正疑惑 | 事実を確認／起用を保留／契約を続けて説明する | 人気・信用・契約の負担が絡む |
| 配信設備から情報が漏れている？ | 配信を止める／設備と権限を点検／外部に調査を頼む | 集客のための設備投資が、管理の責任も増やす |
| エースディーラーの退職 | 待遇を上げる／後任を育てる／店長が現場に入る | 人に頼って伸びた店の弱点が出る |
| 大会は満員。でも普段の常連が来なくなった | 大会を広げる／開催を減らす／時間帯を分ける | 満席と経営の成功が一致しない |
| 近隣から苦情。原因は店内ではなく帰り道 | 退店の誘導／スタッフを配置／営業時間を見直す | 店の外まで含めた運営が要る |
| 近くの店が摘発され、うちにも問い合わせが殺到 | 営業内容を説明する／予定どおり営業／企画を点検する | 自店がきちんとしていても、外の出来事に揺さぶられる |

- 不正疑惑は「外部の人がリアルタイムで助言する（共謀）」と「機器から情報が漏れる」を別の事件にする。中身に幅が出る。
- **調べた結果、不正ではなかった回も入れる。** 「告発されたら即出禁」が常に正解だと判断にならない。調査中の説明や、当事者を守れたかも評価に入れる。
- 実名は使わない。

## 3. 評判を一つの数字にしない

| 指標 | 意味 |
|---|---|
| 知名度 | 店を知っている人がどれだけいるか |
| 信頼 | 公平で、説明が一貫している店だと思われているか |
| 初心者の居心地 | 初めて来た人が、また来たいと思うか |
| スタッフの余力 | 忙しさをさばけて、教育や確認をする余裕があるか |

- 指標どうしが食い違うのが面白さ。炎上で知名度は上がるが、信頼は落ちる。満卓だが、スタッフが疲れてミスが増える。
- 全部を常に数字で出す必要はない。見下ろし画面に出す：初心者が入口で帰る、スタッフの動きが慌ただしくなる、卓で口論が起きる。店を眺める意味が生まれる。

## 4. 確率設計の見直し（v0.2は狙いを満たしていない）

v0.2の検証には、次の穴がある。

1. **目標が未達。** 目標は「違法の期待値は合法の0.95倍以下」なのに、最善の違法戦略は0.96倍だった。
2. **比較の条件が足りない。** 全体で最強の合法店と比べていた。同じ立地・同じ資金・同じ経過月で比べないと、駅前や郊外を選んだ人には違法が正解になりうる。
3. **最後だけ違法にする攻略がある。** `scripts/sim_endgame.py` で確かめると、v0.2の推奨値で終盤（55か月目から）だけ違法にすると、合法の**1.23倍**になる（逮捕17%）。利益の薄い店（売上:費用=1.3:1）では**1.79倍**。60か月で採点が終わるので、その後の不利益を受けずに済むため。
4. **平均で合法が強くても、最高記録狙いでは違法が正解になる。** 何度でも挑戦できて最高記録だけを競うなら、上振れの大きい違法を繰り返す動機が残る。「平均で合法が強い」と「ランキングで違法が最適にならない」は別の要件。

方針：

- **通常ランキングは、適法に運営したプレイだけを対象にする。** 違法を選んだプレイも最後まで遊べて、別の結末として残す。
- 全体最高利益のランキングを作るなら、違法への挑戦を促す性質があると受け入れたうえで作る（作るかどうかは未決）。
- 終盤の攻略は、ランキング対象外にすることで実質的に塞ぐ。加えて、最終月に「残存リスクの精算」を入れるかを検討する。
- **不利益を重ねすぎない。** 「罰金＋強制停止＋売上減＋逮捕率の倍増」が一度に来ると、立て直すより最初からやり直すほうが楽しくなる。失敗の後にも操作する価値を作る：営業方針の変更、スタッフ教育、信頼回復の施策。
- 検証では固定戦略だけでなく、次を必ず含める：途中でやめる／命令後に変える／終盤だけやる／複数のアクションを併用する。どれも、**同じ立地・資金・経過月の合法と比べる**。

## 5. 法的な表現は、免責文ではなくゲーム本体を直す

| v0.2の表現・作り | v0.3 |
|---|---|
| 全アクションに「改善命令」と「逮捕」 | ゲーム上の不利益イベントと、現実の法的手続きを分ける。ゲーム内の名前は「是正指摘」「摘発エンド」など |
| 改善命令と同時に罰金 | 架空の負担は「是正対応費」と呼ぶ。刑事罰の罰金と混ぜない |

```

予測FCF_t = 直近12か月のFCF × (1+g)^t
ターミナルバリュー = 5年目のFCF × (1+1%) ÷ (r − 1%)
```

| 要素 | 決まり方（ゲーム上） |
|---|---|
| 直近12か月のFCF | 営業利益 − 維持投資（卓1台あたり月2万円） |

| 割引率 r | 基本25%（小規模店舗のリスク）。スタッフ依存・信頼の低さで上がる。**是正指摘1回ごとに+10%** |

| 1年目 | 2,754万円 | 2,203万円 |
| 2年目 | 2,809万円 | 1,798万円 |
| 3年目 | 2,865万円 | 1,467万円 |
| 4年目 | 2,923万円 | 1,197万円 |
| 5年目 | 2,981万円 | 977万円 |
| 6年目以降（ターミナルバリュー 1億2,545万円） | — | 4,111万円 |
| **企業価値（買収額）** | — | **1億1,753万円** |

同じ店でも、是正指摘を1回受けて r=35% になると8,265万円（約0.7倍）。

# v0.8（実装済み）：店のコンセプトと客層

健全営業の中でも、店づくりで勝ち方が変わるようにした（レビュー指摘への対応）。

| コンセプト | 最初の客層（常連・初心者・大会客） | 特徴 |
|---|---|---|
| 初心者中心 | 25%・60%・15% | 初心者が常連に育つ速さ×1.6。居心地+12、余力−2 |
| 競技志向 | 35%・25%・40% | 大会客が多い（単価×1.2）。居心地−8、大会・配信の運営費 月10万円。不正疑惑・情報漏えい・プロの事件が起きやすい |
| 交流中心 | 55%・35%・10% | 常連が厚い。居心地+6、信頼+4。連絡先・常連・近隣の事件が起きやすい |

- 客層は毎月動く。初心者は居心地しだいで常連に育ち、常連は居心地と信頼が低いと離れる。大会客はコンセプトと知名度で決まる
- 常連が厚いほど、客数が増え（最大±15%）、競合の出店の打撃が減り（最大−40%）、店の値段の成長率が上がる
- 事件の選択が客層を動かす（例：「大会を広げる」で大会客+12%・常連−8%）

# v0.9（実装済み）：2号店とFC展開

# v1.0 方針（未実装）：設計して、結果を見て、仮説を立て直すゲームにする

外部レビュー（2回目。経営ゲーム6作品の分析つき）を受けての方針。v0.7.1のレビュー修正は維持し、違法要素の扱い（摘発エンドなど）は現状のまま。

## 中心に置くループ

```
開業前に設計する（立地・広さ・料金・人材・設備・企画）
  → 営業で結果が返る（どこが詰まっているかが店内に見える）
  → 原因を見つけて手を打つ
  → 終了後、設計判断までさかのぼって振り返る
  → 同じ条件で、設計だけ変えて再挑戦する
```

## 決めること

| # | 方針 | 中身 | 参考にした面白さ |
|---|---|---|---|
| A | 開業前の設計は減らさない | 「おすすめ設定ですぐ始める」と営業中のヒントは撤去する。代わりに、選んだ設計の意味が読める開業画面にする（固定費・損益分岐・需要の幅・起きやすい詰まり）。正解の印は付けない | 設計そのものが遊び |
| B | コンセプトを選び、組み合わせで色が変わる | **決定**：コンセプトは選ぶ形を残す（下の4つ）。コンセプトが客層・単価・リスクの土台を決め、設備・企画・料金・人材の組み合わせで、さらに店の色が変わる | Capitalism Lab |
| C | 詰まりを見つけて直す | 毎月「集客不足／席不足／人手不足／定着不足」を判定し、店内に見せる（入口の列、空卓なのに案内待ち、説明待ちで帰る初心者、新規ばかりで常連が増えない）。収支パネルに「今月の詰まり」 | Production Line |

## B. コンセプト（決定：4つ）

| コンセプト | 得るもの | 背負うもの | 条文の扱い |
|---|---|---|---|
| 初心者歓迎 | 初心者が多く、常連に育ちやすい。口コミで知名度が伸びる | 単価は低め。教える手間で余力が削られる。強い客は物足りず離れる | — |
| レベルの高いゲーム | 強豪の常連と大会客が集まる。単価が高い。配信・大会と相性が良い | 公平さが厳しく見られる（不正疑惑の事件で信頼が大きく動く）。初心者が入口で引き返しやすい | — |
| 射幸心の高いゲーム | 客数も単価も一番伸びる | 是正指摘を受けやすい（グレー寄り）。信頼が下がりやすい。換金や景品への誘惑の事件が起きる | 「射幸心」に関わる風営法の条文を、e-Govから正本に入れてから実装する |
| 酒と美女 | 飲食で単価が上がる。夜の時間帯に強い。交流の常連がつく | 人件費が高い。酔客のトラブルが増える。深夜営業に寄りやすい。接客が「接待」に当たると、別の許可区分が要る扱いになり、許可なしなら黒の営業になる | 「接待」に関わる風営法2条（営業の区分）と解釈運用基準の記載を、一次ソースから正本に入れてから実装する |

- コンセプトは営業スタイル（換金・グレー・預入）とは別の軸。たとえば「射幸心の高いゲーム × 預入のみ」もありうるが、是正指摘の確率は上がる
- 表示名は指定どおり。ゲーム内の説明では、特定の性別を前提にしない書き方にする（「接客スタッフ」など）
- 黒・グレー・健全と同じく、コンセプトのリスクはゲーム上の扱いで、適法性の判定ではないことを画面に出す

## J. 売却は「バリュエーション・レポート」で決める（投資銀行の評価資料のように）

売却額は、3つの方法で店の価値を出し、その**中央の値**を採用する。

| 方法 | 計算 | 幅の出し方 |
|---|---|---|
| DCF | 直近12か月のFCFから5年分を予測し、割引率で今の価値に直し、6年目以降をターミナルバリュー（永久成長）で足す。今の仕組みを使う | 割引率±2.5%・永久成長率±1%の感応度表の端 |
| 類似取引比較（Comps） | 架空の「似た店の売買事例」6〜8件から、EV/EBITDA・EV/売上・1席あたりEVの倍率の中央値をとり、自店の直近12か月の数字に掛ける。立地・規模・信頼・常連の厚さ・オーナー依存で上下に補正する | 倍率の上位25%と下位25% |
| 清算価値（純資産） | 店をたたんだら残るもの。敷金（原状回復費を引く）＋卓・設備の中古売却額＋内装の残存価値（処分時はほぼ0）。帳簿の純資産と、急いで売る清算価値の2つを出す | 帳簿価額と清算価値 |

- **株式価値への橋渡し**：3つの方法で出すのは事業の価値（EV）。最終手取り額は「EV＋手元資金−借入」で出す（今の計算と同じ考え方）
- **フットボールフィールド**：3つの方法の幅を横棒で並べ、中央値の線と採用額を示すグラフを出す
- **レポートの構成**：要約（採用額と根拠）→ フットボールフィールド → DCF（年ごとの表と感応度表）→ Comps（事例表と補正）→ 清算価値の内訳 → EVから最終手取り額への橋渡し
- **年次決算にも同じレポート**を「中間評価」として出す。毎年、自分の店がどの方法で高く・安く見られているかが分かる
- **買収前調査との関係**：黒の営業が見つかれば、DCFとCompsは継続的なキャッシュフローを前提にできないので不採用になり、清算価値だけになる（いまの「ハコとしての価値」）。グレーなら、DCFとCompsを減額する
- **架空の事例**：Compsの事例は実在の店名・企業名を使わず、架空であることを表に明記する。倍率は小規模店舗としてもっともらしい範囲に置く（数値はゲーム用の仮置き）

**決定**：採用額は「3つの中央値」と「清算価値」の高い方。たたんだ方が得なら、それより安くは売らない、という考え方。赤字の店では清算価値が下支えになる。

## 実装の順番（案）

1. **A・C・G**：おすすめ設定を撤去。詰まりの判定と店内での見せ方、振り返りの因果表示（今ある仕組みの上に足せる）
2. **D・B**：設備・企画の投資を入れ、コンセプト3択を置き換える
3. **E・F**：スタッフの個人化、成長フェーズ、店長と属人性
4. **J**：バリュエーション・レポート（DCF・Comps・清算価値の中央値、フットボールフィールド）
5. **H**：同じ条件での再挑戦と比較
6. **I**：組み合わせの釣り合いを自動プレイで検証して調整

### v1.4.3〜v1.5.5で変えた前提（まとめ）

| 前提 | 以前 | いま |
|---|---|---|
| 人件費と営業時間 | 人数も給与も営業時間に比例（二重） | 人数だけが営業時間に比例、給与は一人ひとりの月給 |
| 朝・昼の客 | 帯の重みは固定（朝0.2・昼0.5） | 店が続き知名度が上がるほど増える（最大 朝×3・昼×2.2） |
| 店の大きさと客数 | 立地の客数は卓数によらず一定 | 6卓以上は遠くからも来る：客数×(卓数÷5)^α（東京0.5・大都市0.3・地方0.3・郊外0.4） |
| 大型店の立ち上がり | 卓数によらず同じ（見込みの50%から12か月） | 6卓以上は出発点が低く期間が長い：÷(卓数÷5)^β・×(卓数÷5)^β（東京0.3・大都市0.4・地方0.5・郊外0.5） |
| 東京都心のぶれと競合 | 物件の当たり外れ±35%、競合の出店5%/月 | ±50%、7%/月 |
| 大型店の固定費 | なし | 大型店の管理費 25万円＋8万円×(卓数−5)/月 |
| 採用・連絡先 | 少人数採用、連絡先交換あり | どちらも削除 |

変えていない前提：立地ごとの基本の客数・客単価・坪家賃・内装費・満席率の上限、卓の値段、健全/グレー/黒の確率と罰則、税金。
